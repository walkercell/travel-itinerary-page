## 机票

**首选：用浏览器打开 Google 机票，直接用自然语言的查询 URL。**把 `{FROM}`、`{TO}` 换成机场三字码，日期写成 `YYYY-MM-DD`。

```
往返直飞：
https://www.google.com/travel/flights?q=Flights%20from%20{FROM}%20to%20{TO}%20on%20{DEPART}%20through%20{RETURN}%20nonstop&curr=CNY&hl=zh-CN
单程：
https://www.google.com/travel/flights?q=One%20way%20flights%20from%20{FROM}%20to%20{TO}%20on%20{DATE}%20nonstop&curr=CNY&hl=zh-CN
```

- 页面经常报"糟糕！出了点问题"。等几秒重新打开同一个 URL，或者把视口调宽到 1280 再试，一般就好了。
- 价格日历（日期网格）里的价格通常读不出来。比较日期时，对每组"出发日 × 返回日"各查一次。浮动范围内挑 4–6 组就够了。
- 航班号默认是折叠的。在页面里执行下面这段，会展开所有航班详情并列出航班号：

```js
const btns=[...document.querySelectorAll('button[aria-label^="航班详情"]')];
const seen=new Set();
for(const b of btns){const l=b.getAttribute('aria-label'); if(seen.has(l)) continue; seen.add(l); b.click(); await new Promise(r=>setTimeout(r,700));}
await new Promise(r=>setTimeout(r,1500));
const t=document.body.innerText;
[...t.matchAll(/([A-Z0-9]{2})\s?\d{2,4}/g)].map(m=>m[0]+' @'+t.slice(Math.max(0,m.index-120),m.index).replace(/\n/g,' '))
```

  页面语言是英文的话，把 `航班详情` 换成 `Flight details`。

- 往返价按"同一航司往返"计算。返程日期换来换去价格不变时，说明价格主要由去程决定。
- 搜不到直飞时，告诉用户附近哪个机场有直飞，以及从出发地过去的路程。
- 有两个机场的城市要看清机场代码，确认转机或回程用的是哪一个，比如东京的成田 NRT 和羽田 HND。

## 酒店

- **有酒店搜索工具时**（例如 RollingGo 的 MCP）：
  - `searchHotels`：按城市、景点、机场搜酒店，`hotelTags.preferredBrands` 填用户偏好的品牌，返回参考价和预订链接
  - `getHotelDetail`：查房型价格，包括能不能免费取消、含不含早
  - 返回结果很大时，用 `jq` 过滤出"各房型最低价"，不要把整个结果读进上下文
- 搜索结果按"城市"定位时，偶尔会跑到同名的其他地方。这时改用酒店名、英文城市名，或按"景点"类型搜。
- 某家酒店"所选日期已售罄"只代表这一个渠道，提醒用户去其他平台再看看。
- 有些酒店集团的官网会拦截自动化访问，这类价格让用户自己在官方 App 里查。
- 对比价格时，优先用"可免费取消"的那档价格。
- 酒店图片可以直接用搜索结果里的图片地址。

## 门票与开放时间

- 搜索"<景点> entrance fee <年份>"或"<城市> museum entrance fees <年份>"，至少看 2 个来源。
- 多个来源的数字不一样时，写成区间，或者注明"只有一个来源"、"待确认"；不要挑一个当成确定价格。
- 一定要查清：每周哪天闭馆、宗教场所的礼拜时段、当地节假日的开放调整。
- 学生证优惠：很多地方只认本国学生证。搜不到官方说明时，就写"到窗口试试"，不要算进预算。

## 汇率

- 搜索"<货币> exchange rate <月份 年份>"，用最近日期的那个值，并在页面上写明日期。
- 通胀高的货币，景点常常直接按欧元或美元标价。预算统一换算成用户的货币，写清"1 欧元 ≈ ¥8"这类假设。

## 当地交通与杂费

- 机场到市区：机场大巴、出租车、预约接机都列成可选方案，各给价格。
- 市内交通：按"交通卡 + 每人每天大约几次 × 单价"算，单价写进 `detail`。
- 包车、跟团、当地活动这类没有公开价的，标"估"，并说明是怎么估的。
- 签证、电子签：认准目的地的官方网站，提醒用户避开收高额服务费的代办站。
- 上网：eSIM（第三方）和当地运营商游客卡各给一个价格，作为两个方案。

## 景点图片

运行 `python3 scripts/wiki_images.py --trip trip.json --write`。查找顺序是：英文维基百科的页面主图 → Wikimedia Commons 文件搜索。

注意几种情况：

- 维基百科有时返回的是 logo 或示意图。脚本会过滤掉明显的 logo，其余靠人抽查。
- 找不到专门的照片时，用同一区域的照片代替，不要放一张不相关的图。
- 维基媒体接口请求太频繁会被限流，脚本里每次请求间隔 1 秒。

## 地图底图

- 模板默认用 **Esri World Street Map** 瓦片，不需要 API key，从本地文件（file://）打开也能加载。
- **CARTO** 底图现在需要 API key，不加 key 会显示"API KEY REQUIRED"水印。
- **OpenStreetMap 官方瓦片服务器**会拒绝没有 Referer 的请求，本地文件打开时就是这种情况。
- 地图库 Leaflet 1.9.4 从 cdnjs 加载。底图和地图库都需要联网；离线时页面会显示提示文字，其他板块不受影响。
